# OV5620 register subset used by the F50

Source: OmniVision "OV5620 Color CMOS QSXGA (5.17 MPixel) CAMERACHIP", datasheet
version 1.3, 2007-02-15 (CLCC package), Table 11. SCCB write address 0x60 (7-bit 0x30).
Only the registers this project touches are listed. "F50 boot" is the value the
scanner's firmware leaves at power-on (`engine-regs-poweron.txt`).

| Reg | Name | Default / F50 boot | Bits |
|---|---|---|---|
| 0x00 | GAIN | 00 / 00 | [6:0] analog gain: (b6+1)(b5+1)(b4+1)(1+b[3:0]/16), 1x..16x. b7 must be 0. Manual only when COM8[2]=0 |
| 0x01 | BLUE | 80 / 80 | digital AWB blue gain, 0..4x (0x40 = 1x as the Windows driver uses it) |
| 0x02 | RED | 80 / 80 | digital AWB red gain |
| 0x16 | GREEN | 80 / 80 | digital AWB green gain |
| 0x03 | COM1 | 4A / 40 | [7:6] dummy frames, [3:2] VEND LSBs, [1:0] VSTRT LSBs |
| 0x04 | REG04 | 00 / 25 | [7] mirror, [6] flip, [2:0] AEC[2:0] |
| 0x10 | AEC | 63 / 00 | AEC[10:3] |
| 0x45 | REG45 | 00 / 00 | [7:6] AGC[9:8], [5:0] AEC MSBs (the table says AEC[15:10] here and AEC[16:11] under 0x10; with 0x10 = AEC[10:3] the consistent reading is AEC[16:11]) |
| | | | Exposure TEX = tLINE x AEC; capped at one frame period |
| 0x0c | COM3 | 08 / 08 | [2]=0 vertical size 1944 in full mode, [0]=0 horizontal 2592; [3] vertical blanking 24 lines (or DMLN 0x46/0x47) |
| 0x11 | CLKRC | 00 / 43 | [6] divider enable; CLK = PLL/2 if [5:0]=0, else PLL/((n+1)*2) |
| 0x12 | COM7 | 00 / 00 | [7] soft reset, [6:3] resolution (0000 = full 2592x1944, no binning) |
| 0x13 | COM8 | C7 / 41 | [7] fast AEC, [2] AGC auto, [1] AWB auto, [0] AEC auto |
| 0x14 | COM9 | 40 / 40 | [7:5] AGC ceiling, [2] drop VSYNC with dropped frames, [1] drop frames whose exposure is out of tolerance |
| 0x15 | COM10 | 00 / 02 | [5] PCLK gated by HREF, [4] PCLK edge, [3] HREF polarity, [1] VSYNC polarity |
| 0x17/0x18 | HREFST/HREFEND | 12 / B4 | 8 MSBs, 3 LSBs in REG32[2:0]/[5:3]; units of 2 pixels |
| 0x19/0x1a | VSTRT/VEND | 01 / F4 | 8 MSBs, 2 LSBs in COM1; units of 2 lines |
| 0x24/0x25 | AEW/AEB | 78 / 68 | AEC/AGC luminance window (also the "tolerance" for COM9[1]) |
| 0x2d/0x2e | ADDVSL/ADDVSH | 00 / 80,01 | lines added to VSYNC width (F50 boot adds 0x180 lines) |
| 0x2f | YAVG | auto | average luminance |
| 0x32 | REG32 | 00 | [7:6] PCLK divide (10 = /2, 11 = /4), [5:0] H window LSBs |
| 0x46/0x47 | DMLNL/DMLNH | 00 / 60,00 | vertical blanking lines |
| 0x63 | COM34 | 00 | [6] de-noise enable |
| 0x80 | DSPEN | 01 / 01 | [4] colour bar, [1] raw before CIP, [0] new CIP enable |
| 0x81 | DSP01 | 00 / 00 | [2] black-pixel, [1] white-pixel, [0] both cancelling |
| 0x83 | DGCTRL | 80 / 85 | [1:0] digital gain 1x/2x/4x/4x |
| 0x89 | DSP09 | 29 / 20 | [5] AWB gain enable (applies 0x01/0x02/0x16) |
| 0x8b | DSP0B | 1F / 3F | [5] gamma enable |
| 0xa8/0xa9 | BOTLMT/TOPLMT | 10,F0 / 0A,F0 | output clip limits |
| 0xb8..0xba | R/G/B gain limits | F0 | |

Output: 10-bit raw Bayer, first line after VSYNC is `B G B G ...`, second `G R G R ...`
(BGGR). The F50 has an 8-bit slave FIFO, so only 8 data lines reach the USB chip; see
NOTES.md for what that means for bit depth.

Not in the datasheet: no MSB/LSB swap register is documented ("can be swapped with
the control registers" but the table has none), and registers 0x84/0x85 are reserved.
